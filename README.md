# My Agent Skills

Reusable task instructions for AI assistants. No skills are currently included; the instructions below apply once skills are available.

## Installation

### Skills CLI

With [Node.js](https://nodejs.org/) installed, run:

```bash
npx skills add XIAN-SHENG-576692/my-agent-skills
```

See [Skills CLI](https://github.com/vercel-labs/skills) for supported assistants and options.

### ZIP download

After a release is published, download a skill ZIP from the [latest release](https://github.com/XIAN-SHENG-576692/my-agent-skills/releases/latest) and import it into an assistant that supports skill uploads. Private repositories require access.

## Use a skill

Ask your assistant to use the installed skill by name and supply the input described in its instructions. Review the output before sharing.
